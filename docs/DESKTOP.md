# デスクトップ版（Mac・Windows）

メニューバー（Windows ではタスクバーの通知領域）に常駐して、ホットキー（Mac は ⌘⇧M、Windows は Ctrl＋Shift＋M）・アイコン・画面の隅（ホットコーナー）で、Memoca の即席メモを小さな窓で出すアプリです。書いたメモは Inbox に入ります。メニューの「Memoca を開く」で、メモの一覧や編集もできる大きいウィンドウ（Memoca 全体）も開けます（0.3.0 から）。

- 中身は Web 版の即席メモの画面（`https://memoca-app.vercel.app/quick`）そのものです。アプリに Memoca の画面を同梱していないので、Web 版を更新すると、アプリも次に窓を隠したときに新しい版になります。
- 即席メモの窓は、起動したときに読み込んで隠しておきます。呼ぶとすぐに出ます。即席メモの窓に出るのは、即席メモとログインの画面だけです。
- Memoca 全体のウィンドウは、ブラウザで開く Memoca と同じものです。開いたときに読み込み、閉じると消えます（大きさと位置は覚えています）。ログインは即席メモと共通です。
- パソコンにログインすると、アプリも隠れたまま起動します（メニューの「ログイン時に起動」で切り替え）。
- アプリ自身の新しい版は、自動で入ります（0.2.0 から。下の「更新」）。

## 入れ方（Mac）

アプリには Apple の署名がありません（Apple Developer Program に入っていないため）。そのため、初めて開くときだけ、macOS に「開いてよい」と伝える手順が要ります。

1. [GitHub のリリース](https://github.com/mocaluna0117/memoca/releases) から `Memoca_<版>_universal.dmg` をダウンロードします（Apple シリコンと Intel の Mac のどちらでも動きます）。
2. `.dmg` を開き、`Memoca` を「アプリケーション」フォルダにドラッグします。
3. 「アプリケーション」の `Memoca` を開きます。「“Memoca”は開いていません」または「開発元を確認できません」と出たら、「完了」（または「キャンセル」）を押します。
4. 「システム設定」→「プライバシーとセキュリティ」を開き、下の「セキュリティ」にある「“Memoca”は Mac を保護するためにブロックされました」の「このまま開く」を押します。Mac のパスワード（または Touch ID）を求められたら入れます。
5. もう一度 `Memoca` を開き、「このまま開く」を押します。次からは、そのまま開きます。

- macOS 14 までは、Finder で `Memoca` を右クリック（Control ＋クリック）して「開く」を選んでも開けます。macOS 15 からは、この方法は使えません。
- アプリを新しい版に入れ替えたときは、同じ手順がもう一度要ることがあります。
- 「“Memoca”は壊れているため開けません」と出て、上の手順でも開けないときは、「ターミナル」で次を実行してから開き直します（ダウンロードしたときの印を外します）。

  ```sh
  xattr -dr com.apple.quarantine /Applications/Memoca.app
  ```

## 入れ方（Windows）

アプリには Microsoft の署名がありません。そのため、初めて入れるときだけ、Windows の確認を通る手順が要ります。

1. [GitHub のリリース](https://github.com/mocaluna0117/memoca/releases) から `Memoca_<版>_x64-setup.exe` をダウンロードします。
2. ダウンロードしたファイルを開きます。「Windows によって PC が保護されました」と出たら、「詳細情報」を押し、「実行」を押します。
3. インストーラーの案内に沿って進めます。自分のユーザーだけに入り（管理者の権限は要りません）、終わるとアプリが起動します。
4. アプリは、タスクバーの右の通知領域に Memoca のアプリのアイコンとして常駐します（Mac のメニューバーの ⚡ ではありません。このドキュメントの「⚡ アイコン」は、Windows ではこのアイコンのことです）。見当たらないときは、通知領域の「^」（隠れているインジケーター）の中にあります。いつも出しておくには、「設定」→「個人用設定」→「タスクバー」→「その他のシステム トレイ アイコン」で Memoca をオンにします。

- 窓の中身を表示するのに Microsoft Edge WebView2 を使います。Windows 10・11 には入っていますが、ないときはインストーラーが取ってきます。
- `Ctrl＋Shift＋M` は Microsoft Teams のミュートと同じキーです。Teams を使うときは、下の「設定」でホットキーを変えてください。

## 初めてのログイン

Google は、アプリの窓の中でのログインを受け付けません。そのため、いつものブラウザでログインして、アプリに戻ります。

1. 初めて開くと、窓にログインの画面が出ます。「ブラウザでログイン」を押します。窓に、確認用の文字（例：`1A2B-3C4D`）が出ます。
2. いつものブラウザで Memoca のページが開きます。まだログインしていなければ、Google でログインします。
3. ページに、ログインするアカウントと、確認用の文字が出ます。窓の文字と同じなら「デスクトップ版にログインする」を押します。しばらく前にログインしたブラウザでは、確認のため、先に Google のログインをもう一度通ります。
4. 「デスクトップ版の Memoca を開く」を押します。ブラウザが「“Memoca”を開きますか？」と聞いたら「開く」（許可）を選びます。
5. アプリの窓がログインして、即席メモが出ます。

- ブラウザからアプリが開かないときは、ブラウザの「開かないときは、コードを表示」を押し、出たコードをアプリの窓の「コードを貼り付け」に入れて「ログイン」を押します。ブラウザに移ると窓は隠れるので、⌘⇧M かメニューバーの ⚡ アイコンで出し直します。
- 「ブラウザでログイン」を押してから 10 分以内、コードが出てから 3 分以内に済ませます。過ぎたときは、最初からやり直します。「ブラウザでログイン」を何度か押したときは、最後に開いたページで続けます。
- 確認用の文字が窓と違うときや、「ブラウザでログイン」を押していないのにページが開いたときは、続けずにページを閉じます。
- コードは、アプリの窓の「コードを貼り付け」の欄にだけ入れてください。人に教えないでください（Memoca を名乗る相手にも）。
- アプリのログインは、ブラウザのログインとは別です。ブラウザでログアウトしても、アプリはログインしたままです。アプリをログアウトするには、メニューの「ログアウト」を使います。ほかの端末から終わらせるときは、Web 版の「設定」→「アカウント」の「ほかの端末をすべてログアウト」を使います。

## 使い方

| したいこと | 操作 |
|---|---|
| 即席メモを出す・隠す | ⌘⇧M（Windows は Ctrl＋Shift＋M）。または ⚡ アイコンをクリック |
| 保存する | ⌘ ＋ Enter（Windows は Ctrl ＋ Enter）。窓はそのままで、欄が空になり「保存しました ・ メモを開く」と出ます |
| 画像を入れる | 欄に貼り付けるか、ドラッグするか、画像のアイコン（画像を追加）から選びます |
| 保存したメモを開く | 「メモを開く」。Memoca 全体のウィンドウで、そのメモが開きます |
| メモの一覧や編集 | 窓の上のウィンドウのアイコン（Memoca を開く。0.4.1 から）か、⚡ アイコンを右クリックして「Memoca を開く」。即席メモの窓は隠れ、書きかけは下書きとして残ります |
| 閉じる | Esc か ×（⌘W でも）。書きかけは下書きとして残り、次に出したときに戻ります |
| 動かす | 窓の上の「即席メモ」の帯をドラッグします |

ほかのアプリをクリックすると、窓は隠れ、キーボードは前に使っていたアプリに戻ります。出したままにしたいときは、⚡ アイコンを右クリックして「ピン留め」にします。ピン留めした窓は、動かした場所から動きません。

### Memoca 全体のウィンドウ

- ⚡ アイコンのメニューの「Memoca を開く」か、即席メモの上の「Memoca を開く」（0.4.1 から）で開きます（開いていれば、そのまま前に出ます）。即席メモの「メモを開く」でも開きます（開いていれば、そのメモに移ります）。
- 中身はブラウザの Memoca と同じです。ウィンドウの中の「⚡ 即席メモ」や Q キーは、アプリの即席メモの窓を出します。
- Memoca 以外のサイトへのリンクは、いつものブラウザで開きます。
- メモの画像を何枚か選んで ⌘C（Windows は Ctrl＋C）すると、Finder（エクスプローラー）でファイルをコピーしたときと同じ形で、画像が 1 枚ずつクリップボードに入ります（0.4.2 から）。ChatGPT などのチャット欄やメールに、まとめて貼り付けられます。ファイルはアプリのキャッシュのフォルダに置き、次にコピーしたときとアプリを起動したときに消します。
- PDF の書き出しや添付ファイルのダウンロードは「ダウンロード」フォルダに保存され、保存したファイルが Finder（Windows ではエクスプローラー）で表示されます。
- Mac では、このウィンドウを開いているあいだだけ、Dock と ⌘Tab に Memoca が出ます。⌘W で閉じ、⌘M でしまえます。閉じると、メニューバーのアイコンだけに戻ります。
- Windows では、ふつうのアプリと同じく、タスクバーと Alt＋Tab に出ます。
- アプリの起動から数秒後に、裏でこのウィンドウを用意しておきます。閉じても裏に残り（隠れるだけ）、次に開くとすぐ、閉じたときのまま出ます（0.4.3 から。そのぶんメモリを使います）。隠れているあいだに新しい版のサイトが出ていると、裏で読み込み直します（そのときは金庫が閉じます）。ログアウトすると消え、ログインし直すとまた用意します。
- 大きさと位置（と、最大化していたか）を覚えていて、次に開いたときもそのまま出ます。
- 鍵をかけたメモ（金庫）は、パスキーの代わりに、Mac では Touch ID、Windows では Windows Hello（指紋・顔・PIN）で開けます（0.4.0 から。下の「金庫を Touch ID・Windows Hello で開く」）。

### メニュー（⚡ アイコンを右クリック）

Mac では、Control を押しながらのクリックでも出ます。

- **即席メモを開く**
- **Memoca を開く**：Memoca 全体のウィンドウを開きます
- **ピン留め（ほかをクリックしても隠さない）**
- **ホットコーナー**：なし（既定）・左上・右上・左下・右下。選んだ隅にポインタを 0.3 秒置くと、その隅に窓が出ます。macOS 自身のホットコーナー（「システム設定」→「デスクトップと Dock」→「ホットコーナー」）と同じ隅は避けてください
- **ホットキーを変える（設定ファイルを開く）…**：下の「設定」
- **ブラウザで Memoca を開く**
- **再読み込み**：窓を読み込み直します（おかしいときに）
- **ログアウト**：アプリのログインを終わらせます（ブラウザはそのまま）。Memoca 全体のウィンドウは閉じます
- **ログイン時に起動**：パソコンにログインしたとき、アプリを隠れたまま起動します。初めて起動したときにオンになります
- **アップデートを確認**：新しい版を今すぐ探します。結果は下の「バージョン」の行に出ます
- **バージョン**
- **終了**：⌘Q は効きません。アプリを閉じるのはここからです

Windows では、アイコンを右クリックしてメニューを出します。即席メモの窓は Alt＋Tab の一覧にも、タスクバーにも出ません。

`Memoca.exe --app` で起動すると（すでに動いていれば、動いているアプリに）、Memoca 全体のウィンドウが開きます。

## 金庫を Touch ID・Windows Hello で開く

アプリには Apple の署名がないので、ブラウザと同じパスキーは使えません。代わりに、アプリがパソコンの認証（Mac は Touch ID、Windows は Windows Hello）を呼びます。

- 使い始め：アプリで金庫をパスワードで開くと、「このアプリでも Touch ID で開けるようにしますか？」と聞かれます（「あとで」を選ぶと、しばらく聞きません）。設定の「金庫とロック」→「Touch ID（このアプリ）」からも、パスワードを入れて使い始められます。
- 次から：金庫を開くときに Touch ID（Windows Hello）の確認がすぐに出ます。取り消したときや使えないときは、パスワードで開けます。
- 金庫の鍵の写しを、パソコンの秘密で包んで、このパソコンのアプリの中だけに保存します。サーバーやほかの端末には送りません。パスワードを変えても、そのまま使えます。
- Mac：秘密は 32 バイトの乱数で、ログインキーチェーンに「io.github.mocaluna0117.memoca.vault-unlock」として保存します。Touch ID の確認はアプリがします（Touch ID が使えないときは Mac のパスワード）。パスキーと違い、確認しないと取り出せない仕組み（Secure Enclave）ではないので、Mac にログインした状態で動く悪意のあるプログラムには読まれる余地があります。アプリを更新したあとに一度、キーチェーンの使用を許可するか聞かれることがあります（「常に許可」を選びます）。
- Windows：Windows Hello がアプリ専用の鍵（TPM があれば TPM の中）を作り、その鍵の署名を秘密にします。Windows Hello の確認なしには作れず、パソコンにも保存しません。
- やめるとき：設定の「金庫とロック」→「Touch ID（このアプリ）」の「使わない」。

## 更新

- 窓の中身は Web 版なので、Web 版を更新すると、アプリも次に窓を隠したときに新しい版になります。
- アプリ自身（窓のまわり）の新しい版は、起動して 1 分後と、その後 6 時間ごとに探します。GitHub で公開されたリリースから取り、アプリに組み込んだ鍵で署名を確かめてから入れます。即席メモの窓が出ているあいだと、Memoca 全体のウィンドウを開いているあいだは入れず、どちらも閉じているときに入れて、アプリを起動し直します（書きかけは下書きとして残ります）。メニューの「アップデートを確認」で見つかったときは、窓を閉じてすぐに入れます。
- 0.1.0 には自動更新がないので、0.2.0 だけは手で入れ替えてください。

## 設定

設定は、Mac では `~/Library/Application Support/io.github.mocaluna0117.memoca/settings.json`、Windows では `%APPDATA%\io.github.mocaluna0117.memoca\settings.json` にあります。メニューの「ホットキーを変える（設定ファイルを開く）…」で開けます。

```json
{
  "shortcut": "CmdOrCtrl+Shift+M",
  "hotCorner": null,
  "pinned": false,
  "size": [420.0, 360.0],
  "position": null
}
```

- `shortcut`：ホットキー。`CmdOrCtrl`（⌘）・`Shift`・`Alt`（⌥）・`Ctrl`（⌃）と、キーの名前を `+` でつなぎます。例：`"CmdOrCtrl+Alt+N"`、`"Ctrl+Shift+Space"`。変えて保存したら、メニューの「終了」で閉じて開き直すと使えるようになります。ほかのアプリが使っているキーは登録できません（そのときもアイコンからは出せます）。
- `hotCorner`・`pinned`：メニューで変えるものです。メニューで変えても、ファイルに書いたホットキーはそのまま残ります。
- `size`・`position`：窓を隠したときの大きさと、ピン留めしているときの位置です。アプリが書きます。次に出したとき（起動し直したあとも）、この大きさで、ピン留めしていればこの位置に出ます。
- ファイルの書き方が崩れていると、アプリは既定の設定で動き、ファイルには手を付けません。直して開き直してください。
- Memoca 全体のウィンドウの大きさと位置は、同じフォルダの `.window-state.json` にあります（アプリが書きます）。

## アンインストール（Windows）

1. メニューの「終了」で閉じます。
2. 「設定」→「アプリ」→「インストールされているアプリ」で `Memoca` の「…」→「アンインストール」を選びます。
3. 設定とログインの情報も消すときは、`%APPDATA%\io.github.mocaluna0117.memoca` と `%LOCALAPPDATA%\io.github.mocaluna0117.memoca` を消します。

## アンインストール（Mac）

1. メニューの「終了」で閉じます。
2. 「アプリケーション」の `Memoca` をゴミ箱に入れます。
3. 設定とログインの情報も消すときは、次を消します。
   - `~/Library/Application Support/io.github.mocaluna0117.memoca`
   - `~/Library/WebKit/io.github.mocaluna0117.memoca`
   - `~/Library/HTTPStorages/io.github.mocaluna0117.memoca`（と、同じ名前で終わりが `.binarycookies` のファイル）
   - `~/Library/Caches/io.github.mocaluna0117.memoca`

メモはサーバーと、ほかの端末に残ります。

## 安全のためにしていること

- 即席メモの窓が開くのは、Memoca の即席メモとログインの画面（`https://memoca-app.vercel.app`）だけです。Memoca 全体のウィンドウが開くのは、Memoca のページだけです（ブラウザでのログイン用のページは除く）。ほかのサイトへのリンクは、いつものブラウザで開きます。
- ページがアプリに頼めることは、窓を動かすことと、次の 7 つだけです：窓を隠す、Memoca のページをブラウザで開く、Memoca のページを Memoca 全体のウィンドウで開く、即席メモの窓を出す、ブラウザでのログインを始める、貼り付けたコードでログインする、ログインのコードを受け取る（`desktop/src-tauri/capabilities/quick.json`）。
- ログインのコードは、ログインを始めたアプリだけが持つ秘密（verifier）と組でなければ使えません（PKCE：RFC 7636、アプリでの使い方は RFC 8252）。ブラウザには秘密のハッシュ（challenge）しか渡しません。コードを人に渡しても、ほかの場所では使えません。
- コードと秘密は、アプリが窓のページに直接渡します。URL には載らず、サーバーのログにも閲覧履歴にも残りません。1 回使うと消え、使い回せません。
- コードを作れるのは、この 10 分以内にログインしたブラウザだけです。長く開いたままのブラウザ（席を離れたパソコンなど）から、黙ってアプリのログインを作ることはできません。
- ブラウザのページには、ログインするアカウントと、窓と同じ確認用の文字が出ます。ほかの人が送ってきたリンクで、ほかの人のアプリをログインさせてしまうのを防ぐためです。

## 開発者向け

`desktop/` は、Web 版とは別のパッケージです（Rust と Tauri v2）。Web 版の型チェック・lint・Vercel のビルドには含めません。

### 用意するもの

- Rust（`rustup`、stable。`rustup component add clippy rustfmt`）
- Mac：Xcode のコマンドラインツール（`xcode-select --install`）。Windows：Visual Studio の C++ ビルドツールと WebView2
- pnpm

### ビルド

```sh
cd desktop
pnpm install
pnpm tauri build --bundles app   # desktop/src-tauri/target/release/bundle/macos/Memoca.app
cd src-tauri && cargo test && cargo clippy --all-targets -- -D warnings
```

- `memoca://` のリンク（ブラウザからの戻り）は、「アプリケーション」に入れたビルドでだけ働きます。`pnpm tauri dev` では、コードの貼り付けでログインします。
- 開発用のビルド（`pnpm tauri dev`）は、`MEMOCA_ORIGIN=http://localhost:3100` で手元のサイトを開けます（開発用の Convex は `ALLOW_DESKTOP_SIGN_IN=true`）。リリースのビルドは、この指定を無視して本番だけを開きます。
- アイコンは `pnpm icons` で `public/icons/icon-512.png` から作り直せます（メニューバーのアイコン `icons/tray.png` は別に描いたもの）。
- ビルドには ad-hoc の署名（`tauri.conf.json` の `signingIdentity: "-"`）だけを付けます。Apple シリコンでは、署名のないアプリは開けないためです。

- リリースのビルドは、更新の署名に鍵が要ります（`TAURI_SIGNING_PRIVATE_KEY` と `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`）。鍵はリポジトリの外にあり、GitHub の Secrets にも入っています。鍵をなくすと、入っているアプリはもう自動で更新できません（新しい鍵の版を手で入れ直すことになります）。

### CI での確かめ

`desktop/` を変えて main に push すると、GitHub Actions の「Desktop」が Mac 版と Windows 版を作ります。Windows 版は、そのまま GitHub の Windows の環境で、人が使うのと同じように確かめます（`desktop/scripts/check-windows.ps1`）。

1. インストーラーを無人で入れ、自分のユーザー（`AppData\Local`）に入ったか、`memoca://` のリンクがアプリに結び付いたかを見る
2. 隠れたまま起動して、動き続けるかを見る。もう一度起動しても、`memoca://` のリンクを開いても、アプリが 1 つのままかを見る
3. `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9222` を付けて起動し（アプリがこれを窓の WebView2 に渡す。`window.rs` の `browser_args`）、そのポートから Playwright で窓を動かして、本番のサイトを読み込んで、殻用のログイン画面（「ブラウザでログイン」）が出るか、Windows の殻として名乗っているかを見る。続けて `--app` で起動し、動いているアプリに Memoca 全体のウィンドウが開いて、同じように `/app` に向かうログイン画面が出るかを見る（`desktop/e2e/window.mjs`）
4. 無人でアンインストールして、消えたかを見る

できた `.dmg` とインストーラーは、その実行の成果物（Artifacts）からダウンロードできます。ホットキー、トレイ、ホットコーナー、自動更新など、画面と手で確かめることは、実機で確かめます。

### リリース

1. `desktop/package.json`・`desktop/src-tauri/tauri.conf.json`・`desktop/src-tauri/Cargo.toml` の版をそろえて上げます。
2. `desktop-v<版>`（例：`desktop-v0.2.0`）のタグを push します。
3. GitHub Actions の「Desktop」が `.dmg`・Windows のインストーラー・更新用のファイル（`latest.json` と署名）を作り、下書きのリリースに置きます。中身を確かめて公開します。公開するときは「Set as the latest release」にチェックが入っているか確かめます（アプリは Latest のリリースの `latest.json` だけを見ます。0.3.0 は公開しても Latest にならず、`gh release edit desktop-v0.3.0 --latest` で直した）。公開すると、入っているアプリが自動で更新されます（下書きのあいだは届きません）。

`desktop/` だけの変更は、Vercel の再デプロイを起こしません（`vercel.json` の `ignoreCommand`）。
